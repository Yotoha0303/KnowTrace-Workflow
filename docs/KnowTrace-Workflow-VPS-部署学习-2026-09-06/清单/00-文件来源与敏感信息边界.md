## 完整性检查

归档完成后执行了本地敏感信息扫描，结果为：

- 私钥 PEM/OpenSSH 标记：0；
- 常见云/API Token 格式：0；
- 非示例 `.env`：0；
- SQL dump、Redis RDB、age 密文或 tar.gz 备份：0；
- 非 `example.com` 邮箱地址：0。

该扫描只能发现预设模式，不代替人工审查；它与明确白名单复制、真实 `.env` 排除和 SHA-256 对比共同组成归档验收。

在 PowerShell 中检查服务器副本：

```powershell
$Root = 'C:\Users\Yotoha\Desktop\KnowTrace-Workflow-VPS-部署学习-2026-09-06'
Import-Csv "$Root\清单\服务器文件快照-SHA256.csv" |
  Group-Object RemoteMatch
```

预期只有 `True` 一组，共 40 项。

`VPS源文件权限与大小.tsv` 保留原 Linux mode、owner 和文件大小。Windows 文件系统不会保留 Unix 可执行位；恢复到 Linux 时应参考该清单重新执行 `chmod`，而不是假设 `.sh` 自动可执行。

整个学习包另有 `SHA256SUMS.txt`。它用于发现本地文件后续变化，不代表文件内容安全或业务验收通过。

## 更新规则

服务器配置或脚本变更后，应重新执行：

1. 只复制明确白名单中的非敏感文件；
2. 扫描私钥标记、非示例 `.env`、备份和真实邮箱地址；
3. 比对 VPS 与本地 SHA-256；
4. 更新当前状态快照与问题记录；
5. 重新生成 `SHA256SUMS.txt`。
