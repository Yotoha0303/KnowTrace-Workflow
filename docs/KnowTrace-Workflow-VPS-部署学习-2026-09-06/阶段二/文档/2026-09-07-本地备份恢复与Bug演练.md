# 本地备份、恢复与 Bug 演练

## 隔离边界

使用独立 Compose project `knowtrace-stage2-fixture`；PostgreSQL、MySQL、Redis 为 tmpfs，app/auth 仅监听本机测试端口。没有连接生产网络、挂载生产卷或使用 VPS 数据。

源数据：

```text
PostgreSQL: 2 表 / 5 行
MySQL: 2 表 / 4 行
Redis: 2 个带 TTL key
uploads: 1 文件 / 45 bytes
```

## 发现并修复

1. `BUG-S2-001`：Redis BGSAVE 读到旧完成状态。改用 `rdb_saves` 计数证明本次快照完成。
2. `BUG-S2-002`：`mysqladmin ping` 误判认证就绪。改为用目标凭据执行 `SELECT 1`。
3. `BUG-S2-003`：Compose exec 消费循环 stdin，导致 MySQL 表统计漏项。查询显式读取 `/dev/null`。
4. `BUG-S2-004`：Docker archive API 无法从 fixture tmpfs 导出 RDB。改为无 TTY 二进制流式导出。

失败回归期间，脚本均恢复 app/auth healthy 并保留 `.incomplete-*` 现场。
