# ISSUE-S2-003：终验采集误用认证端口 8081

- 发现时间：2026-09-08 09:48（Asia/Shanghai）。
- 状态：已关闭。
- 影响：第一次重启后综合采集命令在 auth 检查处提前退出；没有造成服务变更或中断。

## 现象

采集命令请求 `127.0.0.1:8081/readyz`，返回 connection refused。实际生产 Compose 将 auth 发布在 `127.0.0.1:8082`。

## 证据与修正

- `docker compose ps` 显示 auth 为 `127.0.0.1:8082->8082/tcp` 且 healthy。
- 用正确端口访问 `/readyz` 返回 `code=0`、`status=ready`。
- app 3000、Nginx 8080、公网 HTTPS 和所有容器同时通过。

结论：这是终验命令的端口抄写错误，不是 auth 服务故障。修正端口后重新采集完整证据；没有重启容器。

## 改进

运维脚本应从生产 Compose 渲染结果或统一变量读取端口，避免手工维护第二份端口映射。含 `set -e` 的综合采集要对每项单独记录结果，否则一个非关键检查会截断后续证据。
