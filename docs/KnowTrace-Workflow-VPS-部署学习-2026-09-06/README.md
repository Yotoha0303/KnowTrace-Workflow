# KnowTrace-Workflow VPS 真实项目学习档案（阶段一至三）

更新时间：2026-09-09  
VPS：Ubuntu 24.04.4 LTS，单机约 2 GiB 内存  
公网入口：`https://knowtrace.duckdns.org`  
项目目录：`/opt/knowtrace`

## 本目录的范围

本目录只整理真实项目计划的阶段一至三，不包含第四阶段 Kubernetes/ACK 学习资料。

- 阶段一：上云、域名与 HTTPS、Docker 部署；
- 阶段二：数据备份、压测、Bug、真实故障、版本迭代；
- 阶段三：Prometheus、Grafana、ELK、邮箱告警。

材料同时保留以下四类内容：

1. 可重复执行的安装、部署、验证和回滚命令；
2. 从 VPS 复制的非敏感配置、脚本和 systemd 文件；
3. 已取得的验证证据、故障记录和未完成项；
4. Mermaid 执行流程及与真实生产环境的差距。

## 当前结论

- 阶段一已经完成并持续运行：DNS、HTTPS、容器化应用和分层反向代理均有证据。
- 阶段二服务器侧主线已完成，但缺少“使用当前账号读取已知记录和真实附件”的业务级恢复验收。
- 阶段三核心监控与 ELK 已验证；2026-09-09 快照中 12/12 Prometheus targets UP，ELK 正在运行。
- 外部邮箱告警仍是 `local-only`，没有实际收件证据，因此不能写成“邮箱告警已完成”。
- 这是单 VPS 上的个人 SRE/DevOps 实践项目，不等同于具备 HA、SLA、真实流量和企业值班体系的生产平台。

## 安全说明

本目录没有保存 SSH 私钥、真实 `.env`、邮箱授权码、API Key、Cookie、数据库归档、
Redis RDB、上传附件或真实业务内容。示例 `.env.example` 中的默认值只用于说明字段，
不能直接用于生产。
