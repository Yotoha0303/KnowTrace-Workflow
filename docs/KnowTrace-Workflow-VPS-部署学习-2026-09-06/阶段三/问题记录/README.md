## 四条 ELK 条目为什么留着

不是"舍不得删"，是**教训能迁移到别的栈**：

| 条目 | 可迁移的教训 |
| --- | --- |
| ISSUE-S3-004 | 容器只接 `internal` 网络时，Docker 不会真正建立发布端口 —— 症状是容器内健康、`PortBindings` 有值，但 `NetworkSettings.Ports` 为 `null`。**换任何栈都可能再遇到**。 |
| ISSUE-S3-005 | 退出码 134 + `OOMKilled=false` + 日志含 `JavaScript heap out of memory` = **进程自身堆耗尽**，不是内核 OOM Killer。**Node 系组件通用**（Grafana 也是 Node）。 |
| ISSUE-S3-006 | 自定义字段与 ECS 等既有映射冲突时，不要删索引/映射，**改字段名**。 |
| ISSUE-S3-007 | 退出码 137 + `OOMKilled=false` 常是**停止超时被 SIGKILL**，不是内存不足 —— 别误记成 OOM。 |

它们的**具体 ELK 操作步骤**已无意义，但判断方法仍然有用。
