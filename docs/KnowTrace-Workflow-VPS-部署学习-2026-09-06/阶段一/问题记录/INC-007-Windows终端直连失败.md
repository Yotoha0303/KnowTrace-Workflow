# INC-007：Windows 终端直连域名 80/443 失败

- 时间：2026-09-06
- 影响：本机 PowerShell 中使用 `curl --noproxy '*'` 无法直接访问网站，可能影响命令行运维检查。
- 现象：DNS 正确解析到 `45.64.74.99`，但本机 curl 连接 80/443 超时或失败。
- 排除：VPS 上 Caddy 正常监听；UFW 已放行；服务器公网 IP 回环可用；Let’s Encrypt 多个外部节点完成 HTTP-01；应用内浏览器已加载 `/login`。
- 推断：更可能是当前 Windows 网络、代理软件、运营商路径或本地安全策略差异，不是 KnowTrace-Workflow 服务故障。
- 后续：分别检查系统代理、代理软件分流规则，并换手机网络或另一公网节点复测；不要为了这个现象关闭 VPS 防火墙。
- 状态：未解决，不阻断外部网站上线。
