# INC-002：SSH 密钥首次验证失败

- 时间：2026-09-06
- 影响：尚不能安全关闭密码登录；原密码会话未受影响。
- 现象：服务端接受公钥，但客户端未完成签名，返回 `Permission denied`。
- 根因：PowerShell 调用 `ssh-keygen` 时错误地把两个双引号字符当成了密钥口令；它并不是空口令。
- 处理：使用原口令 `""` 将密钥口令改为空，再次核对密钥指纹。
- 验证：批处理模式的新 SSH 连接返回 UID 0 和主机名 `cloudserver`。
- 教训：Windows 原生命令的空参数传递需要单独验证，不能只看公钥生成成功。
