# 2026-10-19 · M5 修复 F6 · 安全巡检的密钥键名与空值判定

> 依据：M5 三跳链阻断项 **F6**（A7 / G-5 / S4）。

## 1. 缺陷（两处，均实测）

### ① 键名错配 —— 三项判据打在空气上

`security-check.sh` 第 4 节查：

```
AUTH_DB_ROOT_PASSWORD AUTH_DB_PASSWORD JWT_SECRET AUTH_COOKIE_SECRET METRICS_BEARER_TOKEN
```

而真实键名是：

| 巡检里写的 | 真实位置 | 真实键名 |
| --- | --- | --- |
| `JWT_SECRET` | 根 `.env` | **`AUTH_JWT_SECRET`**（`.env.example:18`；`compose.yaml:85,100` 也用它插值） |
| `AUTH_COOKIE_SECRET` | —— | **仓库里不存在这个键**（`grep -rn AUTH_COOKIE_SECRET` 只命中巡检自身） |
| `METRICS_BEARER_TOKEN` | **`.env.observability`** | 键名对，但**查错了文件**（`.env.observability.example:5`） |

旧实现在真实 `.env` 上的判定（HEAD 版本，同一份输入）：

```
JWT_SECRET             state=missing    level=INFO
AUTH_COOKIE_SECRET     state=missing    level=INFO
METRICS_BEARER_TOKEN   state=missing    level=INFO
```

三项全是 INFO = **一条也没真正检查过**，而报告看起来「跑了」。

### ② 空值被判成 missing

`env_key_state` 用 `line="$(sed -n 's/^KEY=//p' | head -n 1)"`，再 `[[ -z "$line" ]] ⇒ missing`。
`KEY=`（键存在、值为空）时 line 也是空串 —— 于是「密钥为空」这个**生产事故**
被降格成 INFO「未在该文件中出现（可能由其他机制注入）」。

## 2. 改动

| 项 | 改动 |
| --- | --- |
| 存在性判据 | 先用 `grep -qE '^\s*KEY\s*='` 判**键在不在**，再取值判空 —— 空值分支可达 |
| 键名 | `JWT_SECRET → AUTH_JWT_SECRET`；删掉不存在的 `AUTH_COOKIE_SECRET` |
| 文件归属 | `METRICS_BEARER_TOKEN` 改查 `$OBSERVABILITY_ENV_FILE` |
| `missing` 的级别 | INFO → **FAIL**：键名写错或文件未初始化，都会让判据变空转；把它记成 INFO 正是本缺陷的成因 |
| 可维护性 | 键与文件用「键<TAB>文件」表驱动，新增密钥时一眼能看出该查哪个文件 |

## 3. 验收（可执行）

被测函数**原样抽出**（`sed -n '/^env_key_state()/,/^}/p'`）后喂四组输入
（`harness/f6-case.sh`，夹具在 `_m5-fix/f6/<场景>/.env`）：

| 场景 | 结果 |
| --- | --- |
| 全部有真实值 | 4 项 `state=set level=OK` |
| `AUTH_DB_PASSWORD=`（空） | `state=empty level=FAIL` |
| `AUTH_JWT_SECRET=change-me` | `state=placeholder level=FAIL` |
| 删掉 `AUTH_JWT_SECRET` 行 | `state=missing level=FAIL` |
| 对照：HEAD 版本的同一组输入 | `AUTH_DB_PASSWORD=` → `missing`（INFO）；三项旧键名全 `missing`（INFO） |

## 4. 边界

- 本机没有 `/etc/ssh`、`ufw`、`journalctl`、`docker`，**整脚本未在本机全量执行**；
  验证的是**第 4 节的状态判定函数**（原样抽出），第 1–3、5–8 节未跑。
- 真机 `.env` 里 `METRICS_BEARER_TOKEN` 若确实缺失，本次改动会从 INFO 变 **FAIL** ——
  这是有意的行为变化：缺 token 意味着观测链断了，应当报出来。
