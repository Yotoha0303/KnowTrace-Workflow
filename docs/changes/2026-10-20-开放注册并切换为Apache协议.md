## 2. 依据与背景

1. **默认开放注册（Registration Enabled by Default）**：
   - 生产在线 Demo（`https://knowtrace-workflow.vercel.app`）与自托管新实例需要允许访客直接注册账号体验完整的知识采集、分类、主张、证据链核验及 RBAC 隔离功能；
   - 此前默认配置为 `AUTH_REGISTRATION_ENABLED=false`，每次部署或测试需显式覆写环境变量；
   - 将配置模板 `.env.example` 与 `compose.yaml` 的降级默认值统一对齐为 `true`，同时保留生产环境通过环境变量覆写关闭（`AUTH_REGISTRATION_ENABLED=false`）的能力，兼顾开箱即用体验与生产可配置性。
2. **开源协议切换（MIT -> Apache License 2.0）**：
   - Apache License 2.0 包含明确的专利授权（Grant of Patent License）与专利反向诉讼终止条款（Patent Retaliation Clause），并对商标使用（Trademarks）做出清晰保护，更适合具备企业级 SRE 体系与完整微服务架构的严肃开源项目；
   - 根仓库与内嵌的 `services/go-user-system` 保持协议一致性，统一为 Apache-2.0，消除多子项目间的授权割裂。
